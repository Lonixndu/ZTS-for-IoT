# Generated outputs

The simulator writes `decisions.csv` and `summary.json` into a run folder such as
`results/demo/`. The API appends its local decisions to `results/api_decisions.csv`.

Generated outputs are excluded from Git by default. Keep reviewed experiment
outputs with their seed, configuration, source version, and data provenance in
your research evidence storage. Demonstration output is synthetic and does not
establish the proposal's performance targets.
