# Example data

`sample_signals.json` contains invented risk values for a local API demonstration.
It does not contain samples from a published IoT dataset. `demo_client.py` submits
these observations with fresh server receipt times and a new demonstration ID.

Real dataset files should go under `data/raw/` and remain outside Git. The research
still needs a documented adapter from real observations or AI outputs to a
chronological device risk sequence.
